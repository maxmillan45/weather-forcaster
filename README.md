# Weather forcaster

A real-time, city-searchable weather application built with **HTML, CSS, and JavaScript**, using the **Open-Meteo API** for geolocation and weather data.  

This project allows users to search any city worldwide and instantly get **current weather information**, including temperature, wind speed, weather code, and time.  

---

## **Features**

- Search weather by **city name**
- Displays **temperature, wind speed, weather code, time, coordinates, and timezone**
- Handles invalid city names gracefully
- Responsive and clean user interface
- Optional **Enter key search**

---

## **Technologies Used**

- **HTML5** – Markup for user interface
- **CSS3** – Styling with modern layout and responsive design
- **JavaScript (ES6+)** – Async fetch calls, DOM manipulation, event handling
- **Open-Meteo API** – Weather and geolocation data
